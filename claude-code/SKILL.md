# Reference Verification (Claude Code)

이미 완성된 문서의 **참고문헌과 인용을 검증**하는 스킬. 새 글을 쓰며 정확성을 강제하는 `accuracy-guard`와 달리, 이 스킬은 **남이(또는 AI가) 이미 써 놓은 인용이 맞는지**를 사후 검증하는 데 특화됐다.

> 이 변형은 **Claude Code(CLI)** 용이다. 로컬 셸(Bash), `pdftotext`/PyMuPDF/`curl`, WebSearch/WebFetch, 서브에이전트(Agent 도구)를 전제한다. Claude 앱(Cowork)에서는 `cowork/SKILL.md`를 사용하라.

핵심 원칙: **출처가 존재한다 ≠ 그 출처가 본문 주장을 뒷받침한다.** 서지 실존만 보면 통과처럼 보이는 문서도, 인용 적절성을 따지면 과확장·변수 오기·자료원 불일치가 드러난다. 두 단계를 분리해 검증한다.

> 가장 비싼 실수는 "출처가 실재하니 OK"라고 끝내는 것이다. 실제 검증의 대부분은 2단계(인용 적절성)에서 일어난다.

---

## 0단계: 인용 수집 (전수)

문서에서 검증 대상 인용을 **빠짐없이** 추출한다.

```
- 본문 인용: (저자, 연도) / 각주·미주 / 참고문헌 목록
- docx: word/document.xml(본문) + word/footnotes.xml + word/endnotes.xml + word/_rels/document.xml.rels(하이퍼링크) 전부 확인
- 내부 자료(기관 제공 PPT·원자료 등)는 외부 검증 대상에서 제외하되, 리포트에 "내부 자료로 분류" 명시
- 각 인용을 "본문 주장 ↔ 인용 출처" 쌍으로 정리하고 번호를 매긴다
```

**번호 통일**: 1단계와 2단계는 동일한 출처 집합이다. 두 단계에 **같은 번호(①②③④)**를 쓰고, 본문 등장 위치는 별도 칸으로 표기한다. (서지 목록 순 vs 본문 등장 순이 어긋나 혼선이 생기는 것을 방지)

---

## 1단계: 서지 실존/정확성

각 출처가 실제로 존재하고 서지정보(저자·연도·제목·발행처/학술지·권호·페이지·URL)가 맞는지 확인한다.

```
1. 웹검색·학술DB(KCI·DBpia·KoreaMed·Google Scholar)·공식DB(law.go.kr, KOSIS, 정부 보도자료)로 실존 확인
2. 출처 5등급 분류(T1 정부공식 / T2 국제·공공 / T3 학술·국책연구 / T4 언론·검증NGO / T5 금지)
3. 판정: PASS(실존·일치) / MISMATCH(존재하나 서지 불일치 — 무엇이 다른지 명시) / FAIL(존재하지 않음 = 환각 → 삭제·재검색)
```

### 출처 5등급 (요약)

| 등급 | 정의 | 사용 규칙 |
|------|------|-----------|
| T1 | 정부 공식 통계·법령·판례 (1차 발행 기관) | 핵심 주장 단독 근거 가능 |
| T2 | 국제기구·공공 연구기관 공식 발간물 | 핵심 주장 단독 근거 가능 |
| T3 | 피어리뷰 학술논문, 국책연구기관 보고서 | 핵심 주장 단독 근거 가능 |
| T4 | 주요 언론, 검증된 NGO 보고서 | 보조 근거만 (T1~T3 보강 시) |
| T5 | 블로그·위키·SNS·출처 불명 | 사용 금지 (인용 시 삭제) |

---

## 2단계: 인용 적절성 (이 스킬의 핵심)

출처 **원문을 직접 읽고**, 본문 주장이 그 원문에 의해 실제로 뒷받침되는지, 논리적으로 타당한 인용인지 판정한다.

```
판정 3분류:
- 뒷받침됨   : 출처 원문이 본문 주장을 직접 지지
- 부분적     : 일부만 지지(과확장 / 대상·범위 어긋남 / 변수명·자료원 불일치 / 방향성만 맞음)
- 뒷받침 안됨: 출처가 그 주장을 다루지 않음(인용 부적절)
```

### 2-1. 원문 직접 판독 — 추측 금지 (필수)

제목·초록·검색 스니펫만 보고 판정하지 않는다. **반드시 원문 본문을 연다.**

- PDF는 기계 판독한다. WebFetch가 "바이너리/판독 불가"라고 해도 포기하지 말 것 — 대부분 텍스트 PDF이고 요약 모델이 못 읽은 것뿐이다. `pdftotext` 또는 PyMuPDF(`fitz`)로 페이지별 텍스트를 추출하라.
- 정부 보도자료처럼 **JavaScript로 가려진 다운로드**도 직접 받아낸다(`references/pdf-and-deeplink-retrieval.md` 참조).
- 검증 질문에 **주체·시점·수치/변수** 3요소를 명시한다. 나쁨: "그게 맞나?" / 좋음: "488.7만원이 '가구소득'인가 '처분가능소득'인가?"

### 2-2. 페이지·행 핀포인트 (의무)

"출처가 그렇게 말한다"로 끝내지 말고, **어느 페이지 몇 번째 줄**에 그 내용이 있는지 적는다. 원문 표현을 직접 인용한다.

```python
import fitz
d = fitz.open('source.pdf')
for i in range(d.page_count):
    for ln, line in enumerate(d[i].get_text().split('\n'), 1):
        if KEYWORD in line:
            print(f'p{i+1} l{ln}: {line.strip()}')
```

전수검색으로 **부재**도 증거가 된다. 예: 보고서 전체에 '한부모'·'저소득'이 0회 → "저소득 한부모 여성" 주장은 그 출처로 뒷받침되지 않음(과확장).

### 2-3. 자주 나오는 부적절 인용 패턴

- **과확장**: 출처는 A집단을 다루는데 본문은 더 좁은/다른 집단(예: 한부모 여성)으로 확장
- **변수명 오기**: 수치는 맞으나 명칭이 다름(예: 가구소득 ↔ 처분가능소득) — *단, 원문이 실제로 어떻게 부르는지 1차 PDF로 확인할 것. 요약·언론은 표현을 바꾼다*
- **자료원 불일치**: 통계를 엉뚱한 조사에 귀속(예: 국민건강영양조사는 '소득 4분위'로 산출하는데 본문은 '의료급여·차상위' 보장구분으로 기술)
- **방향성만 맞음**: 큰 방향(저소득↑)은 사실이나 구체적 수치·구분은 출처가 보장하지 않음

---

## 3단계: 독립 재검증 (CoVe) — 오판 방지

1·2단계 판정을 **사전 결론 없이 처음부터** 다시 검증한다. **별도 서브에이전트**(Agent 도구)에 원시 사실만 주고 독립적으로 답하게 한다.

```
- 1단계 재검증 에이전트: 출처 N건을 PASS/MISMATCH/FAIL로 백지에서 재판정
- 2단계 재검증 에이전트: "본문 문장 ↔ 출처" 쌍을 주고 뒷받침/부분/안됨 독립 판정
- 사전 판정을 절대 알려주지 않는다(편향 방지). 환각 금지·확정 못 하면 '확정 불가'로 답하게 한다
```

> 실전 효과: 요약·언론 기반으로 'MISMATCH'라 판정했던 항목이, 독립 재검증이 1차 PDF를 직접 열어 'PASS'로 뒤집은 사례가 있다. **원문을 연 쪽이 항상 이긴다.** 충돌하면 1차 출처 원문으로 최종 판정한다.

---

## 4단계: 부적합 인용에 대한 대체 출처 제시

'부분적'·'불일치'·'안됨' 판정 건은 그냥 깎지 말고, **본문 주장을 실제로 뒷받침하는 더 적합한 출처를 찾아 제시**한다.

```
- 주장을 그대로 살릴 수 있는 T1~T3 출처를 검색
- 후보마다 [기관/저자, 연도, 제목, 실제 접속 URL, 등급, 뒷받침하는 구체 수치/문장] 제시
- URL은 실검색으로 확인된 것만. 확신 없으면 후보에서 제외(환각 금지)
- 딥링크 보완: 본문이 홈페이지 URL만 달았으면 해당 통계·지표의 실제 딥링크를 찾아 제시
```

## 5단계: 검증 리포트 산출

별도 파일(`참고문헌_검증리포트.md` 또는 .docx)로 저장한다. 구성:

```
1. 검증 개요 (대상 문서·일자·도구·범위·출처 번호 ①~④)
2. 종합 판정 (서지 PASS/FAIL 집계 · 인용 뒷받침/부분/안됨 집계)
3. 1단계 서지 검증표 (+1차 URL·딥링크)
4. 2단계 인용 적절성 검증표 (본문 위치 + 출처 페이지·행 + 판정)
5. 수치 재검증 (합계·비율·단위)
6. 대체/보강 레퍼런스 (URL·등급·근거)
7. 사람 검토 필요 체크리스트 (부분·불일치·딥링크 교체 등 미해결 항목)
```

표기 규칙: 기관은 **현행 명칭+도메인 병기**(예: '성평등가족부(mogef.go.kr)'). 1·2단계 **동일 번호**.
임계: (FAIL+불일치) ÷ 전체 > 30%면 문서의 근거 전면 재작성을 권고.

PDF/딥링크 취득 실전 기법은 `references/pdf-and-deeplink-retrieval.md` 참조.
