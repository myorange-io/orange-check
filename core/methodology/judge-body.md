## 1. 기계 점검을 먼저 돌린다 — 여기서 대부분이 끝난다

```python
from refver.judge import mechanical_audit, render_audit
from refver.report import load
print(render_audit(mechanical_audit(load("report.json"), corpus="sources", document="제안서.docx")))
```

기계가 보는 것.

| 검사 | 무엇을 잡는가 |
|---|---|
| 계약 | 스키마·필수 항목 위반 |
| **실재** | 근거로 적은 인용문이 그 출처 그 쪽에 정말 있는가 → **지어낸 근거** |
| **부재** | "0회"라고 주장한 검색어가 정말 0회인가 → **거짓 부재 증거** |
| **도출** | 슬롯 표에서 그 판정이 규칙대로 나오는가 → **근거 없는 판정** |
| **전수** | 문서에서 다시 뽑은 인용과 리포트가 맞는가 → **누락** |

`gate`가 `FAIL`이면 채점하지 않는다. 치명 지적을 먼저 고치라고 돌려보낸다.
점수를 매기는 것보다 고칠 곳을 정확히 짚는 것이 낫다.

## 2. 남은 것만 판단한다

기계가 못 보는 것은 넷뿐이다. 각 항목을 0·1·2·3점으로 매기고 **점수마다 근거를 댄다.**

| 항목 | 0점 | 3점 |
|---|---|---|
| 슬롯 정확성 | 슬롯 내용이 원문과 다르거나 지시어가 남아 홀로 읽히지 않음 | 여섯 칸이 원문 표현대로 정확하고 각각 독립적으로 검증 가능 |
| 판정 타당성 | 규칙표와 어긋나는데 사유도 없음 | 규칙표대로거나, 벗어난 경우 그 이유가 원문 근거로 설명됨 |
| 대체 출처 | 없거나, URL이 열리지 않거나, 주장을 뒷받침하지 않음 | 확인된 T1~T3 출처가 주장을 실제로 뒷받침하고 그 문장이 제시됨 |
| 정직성 | 확신 없는 것을 확신처럼 씀 | 못 구한 원문·확정 못 한 판정을 그대로 밝힘 |

**점수를 매길 때 지킬 것.**

- 근거 없이 점수를 주지 않는다. 각 점수에 리포트의 어느 부분을 보고 그렇게 판단했는지 적는다.
- 길다고 잘 쓴 것이 아니다. 분량은 채점 대상이 아니다.
- 리포트가 스스로 "철저히 검증했다"고 쓴 문장은 근거가 아니다. 확인된 것만 센다.

## 3. 두 리포트를 비교할 때는 짝지어 비교한다

같은 문서에 대한 리포트가 둘이면, 각각에 절대 점수를 매겨 비교하지 말고
**같은 인용 번호끼리 나란히 놓고 어느 쪽이 나은지** 고른다. 절대 점수는 기준이 흔들리지만
둘 중 하나를 고르는 판단은 훨씬 덜 흔들린다.

인용별 승패를 세고, 이유가 갈린 항목만 따로 적는다.

## 4. 산출

```
gate       : PASS | REVIEW | FAIL   (기계 점검 결과 그대로)
기계 점수   : 근거 실재율 · 판정 도출 일치율 · 전수 대조
판단 점수   : 네 항목 0~3점과 각각의 근거
고칠 곳     : 치명 → 중대 순으로, 인용 번호와 함께 구체적으로
```

**심판 자신을 의심할 것.** 이 심판이 제대로 재는지는 벤치마크로 확인한다.
`benchmark/`의 정답표가 있는 문서에 대해, 품질이 다른 리포트들의 순위가
`score.py` 순위와 같아야 한다. 다르면 심판이 틀린 것이다.
