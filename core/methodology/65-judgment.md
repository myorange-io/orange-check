## 판단 파일 — 모델이 쓰는 것은 이것뿐이다

인용마다 이만큼만 적는다.

```json
{"citations": [
  {"id": "C01",
   "source": "S01",                     // 실제로 찾아낸 출처. 못 찾았으면 null
   "tier": "T1",
   "biblio": "PASS",                    // 또는 "MISMATCH:year,date" / "FAIL"
   "slots": {
     "who":   ["저소득 한부모 여성", "한부모가족 전체", false],
     "when":  ["2024년", "2024년", true],
     "what":  ["양육비 미수령 비율", "양육비 미수령 비율", true],
     "value": ["72.1%", "72.1%", true],
     "dataset": ["한부모가족 실태조사", "한부모가족 실태조사", true],
     "relation": null                   // 해당 없으면 null
   },
   "at": ["S01:2:14"],                  // 근거 위치. 여러 줄이면 "S01:2:14-16"
   "absent": ["저소득"],                 // 0회로 확인한 말만
   "note": "",
   "biblio_note": "",                   // 서지에 관해 남길 말 (stage1.note 가 된다)
   "tier_violation": false,             // T4 를 핵심 주장의 단독 근거로 썼는가
   "fix": "replace", "fix_cite": "기관, 연도, 제목", "fix_tier": "T1",
   "fix_url": "…", "fix_supports": "이 출처의 어느 문장이 주장을 뒷받침하는가"}
]}
```

슬롯은 `[본문이 쓴 말, 출처가 쓴 말, 일치 여부]` 세 칸이다. 일치 여부만은 기계가 정할 수
없다 — '우식경험률'과 '충치 경험률'은 글자가 달라도 같은 것을 가리킨다. 그 판단이 이
단계의 본체다.

인용문을 직접 적고 싶으면 `{"at": "S01:2:14", "q": "그 문장"}`으로 적는다. 그래도
**그 자리에 정말 있는지 확인한 뒤에만** 들어간다.

**원문을 끝내 못 구했으면 슬롯 대신 `verdict`를 적는다.**

```json
{"id": "C09", "source": "S07", "tier": "T1", "biblio": "PASS",
 "verdict": "INSUFFICIENT_EVIDENCE",
 "note": "매니페스트에는 있으나 원문을 구하지 못했다. 어디까지 찾았는지 적는다.",
 "fix": "none_found", "fix_supports": "코퍼스 7종을 다 뒤졌으나 같은 값을 실은 것이 없다"}
```

이 칸은 **원문을 못 읽었을 때만** 쓴다. 읽고 판단한 인용에는 적지 않는다 — 판정은
슬롯 표에서 나와야 하고, `verdict`를 직접 적으면 그 도출을 건너뛰게 된다.
출처가 아예 존재하지 않는 경우는 이 칸이 아니라 `"biblio": "FAIL"`이다. 실재하는데
못 읽는 것과 아예 없는 것은 다르다.

### 조립기가 막는 것

받아쓰기를 없애는 김에 세 가지가 구조적으로 불가능해진다. 심판이 나중에 잡던 것을
쓰는 자리에서 막으므로 고치는 왕복이 사라진다.

| 막는 것 | 어떻게 |
|---|---|
| 근거 조작 | 인용문을 기계가 원문에서 뽑는다. 직접 적었으면 그 자리에 있는지 대조한다 |
| 판정과 슬롯의 불일치 | 판정과 오류 유형을 슬롯 표에서 도출한다 |
| 없는 부재 | `absent`의 말을 전수 검색해 0회가 아니면 조립을 멈춘다 |
| 유령 인용 | 0단계 인용 목록에 없는 번호를 거부한다 |

조립이 멈추면 **판단이 틀린 것이다.** 조립기를 우회하지 말고 판단을 고친다.
